# Coherence Gates

## Purpose

Coherence gates mark qualitative transitions in how the world can perceive, remember, respond, or transform.

They are not reward tiers. They describe how much relational and informational structure is stable enough to support a new class of consequence.

## Thresholds

| Threshold | Gate | Working meaning |
| --- | --- | --- |
| 0.376 | Pattern Emergence Gate | Signals begin to form recognizable structure. |
| 0.618 | Resonance Gate | Independent signals align strongly enough to reinforce each other. |
| 0.786 | Topological Lock Gate | Relationships and world topology stabilize into a durable configuration. |
| 0.886 | Phase Travel Gate | The world can support movement between states, layers, or phases. |
| 1.000 | Unified Field Gate | Local coherence is fully integrated across intent, memory, signal, and relationship. |

## Usage

Prototype 0 should record the current coherence estimate and nearest gate after meaningful events. Early values may be hand-authored until better metrics exist.

## Open questions

- Are gate values global, local, or both?
- Can different entities perceive different gates?
- Does crossing a gate require sustained coherence or a single peak?
- Which gates should be reversible?
