# Trust Model

## Purpose

Trust is a relational state, not a generic friendliness score. It describes whether an entity, player, network, or world region can rely on another under uncertainty.

## Starter dimensions

- **Consistency**: Do actions match prior behavior and stated intent?
- **Transparency**: Are signals clear enough to interpret?
- **Repair**: Can harm, error, or rupture be acknowledged and addressed?
- **Vulnerability**: What is at risk if trust is extended?
- **Memory**: Which past events shape the current trust state?
- **Reciprocity**: Does trust move in one direction or become mutual?

## State changes

Trust can increase, decrease, fragment, become dormant, become conditional, or be transferred through networks.

Prototype 0 should track trust deltas as consequences, with a short rationale for each change.

## Design caution

Trust should not be reduced to a hidden approval meter. A player may be trusted for courage but not precision, for honesty but not discretion, or for care but not competence.
