# Anchors

## Definition

Anchors are stabilizing points that preserve coherence, memory continuity, or relational orientation.

## Possible forms

- Place
- Symbol
- Entity
- Agreement
- Repeated action
- Shared memory
- Signal pattern

## Mechanical role

Anchors can reduce drift, support repair, preserve identity across phase changes, or help a player interpret ambiguous signals.

## Prototype use

Prototype 0 should include one local anchor near the First Conduit. It may be unnamed at first, but the data model should allow it to be referenced by events and memory traces.
