# Memory Traces

## Definition

Memory traces are durable records of meaningful events and their downstream significance.

## Trace contents

- Source event
- Affected player, entities, and world region
- Trust impact
- Coherence impact
- Signal integrity impact
- Resilience impact
- Narrative or symbolic note
- Decay, reinforcement, or reactivation rule

## Prototype use

Prototype 0 should produce at least one memory trace from the player's first decision gateway. The trace should explain why the world will respond differently later.

## Open questions

- Can memory traces disagree with each other?
- Can a memory trace be repaired?
- How should false or corrupted memories be represented?
