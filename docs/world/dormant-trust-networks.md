# Dormant Trust Networks

## Definition

Dormant trust networks are latent relational structures that can be reactivated, repaired, corrupted, or lost.

## Design role

They let the world remember older alignments without making them immediately visible. A player may encounter effects before understanding the network behind them.

## State possibilities

- Dormant
- Stirring
- Active
- Fragmented
- Corrupted
- Repaired
- Lost

## Prototype use

The First Conduit should brush against a dormant trust network without resolving it fully. This gives the first scenario depth while keeping scope small.
