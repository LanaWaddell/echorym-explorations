# Entities

## Definition

Entities are actors, presences, systems, or world structures that can hold state and participate in relationships.

## Starter entity types

- Player-facing guide
- Anchor
- Conduit
- Trust network
- Memory-bearing location
- Signal source
- Unknown presence

## Entity state

Entities may track coherence, trust posture, signal integrity, resilience, known memories, and relationship links.

## Design caution

An entity does not need to be a character. Some entities may be places, signals, institutions, artifacts, or patterned absences.
