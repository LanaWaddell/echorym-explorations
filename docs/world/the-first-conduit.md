# The First Conduit

## Role

The First Conduit is the starting threshold for Prototype 0. It tests the smallest living version of Echorym's loop:

1. A player enters with intent.
2. The world responds.
3. The player makes choices under uncertainty.
4. Trust, coherence, signal integrity, and resilience change.
5. The world remembers and evolves.

## Scene frame

The player encounters a conduit that reacts to intent before it explains itself. The first response is partial, enough to invite action but not enough to remove uncertainty.

## Required signals

- Player declared intent
- Initial world response
- At least one ambiguous signal
- At least one trust-bearing entity or network
- A memory trace created by the player's choice

## Success criteria

Prototype 0 succeeds if it produces a meaningful trajectory that can be reviewed and replayed without requiring a full game system.
