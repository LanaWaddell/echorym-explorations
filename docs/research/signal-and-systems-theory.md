# Signal and Systems Theory

## Relevance

Signal and systems theory can support models of noise, transmission, feedback, stability, thresholds, and recovery.

## Possible design links

- Signal integrity as a measurable property.
- Coherence gates as threshold transitions.
- Resilience as recovery after perturbation.
- Memory traces as stateful system history.

## Prototype use

Prototype 0 should use simple qualitative signal labels first. Quantitative models can be added after the scenario proves useful.
